# Review screenshots

Your 15 Upwork review screenshots are already placed here and wired into the
gallery in `../index.html`:

```
review-01.png   …   review-15.png
```

To replace one, overwrite the matching `review-NN.png` file with your updated
screenshot (any of `.png`, `.jpg`, `.jpeg`, `.webp` — if you change the extension,
update the matching `src` in `../index.html` too).
